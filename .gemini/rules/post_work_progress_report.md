# Post-Work Progress & Visibility Reporting Rule

Whenever completing coding, refactoring, documentation, or infrastructure tasks:
1. **Mandatory Progress Table:** Always provide a clear, structured table summarizing:
   - **Phase / Module**
   - **Task & Sub-Tasks Completed**
   - **Status (Completed / In Progress / Pending)**
   - **Artifacts / Files Modified**
2. **Synchronize Knowledge Base:** Ensure both `KB/master_plan_product_requirements_document.md` and `KB/development_status_task_board.md` (as well as their root copies) reflect the latest updates, subtasks, and progress after every milestone.
3. **Task Visibility:** Ensure sub-task level visibility so the user can track exact deliverable progress.
